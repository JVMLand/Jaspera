# Jaspera

Through bytecode, ad astra

JVM Assembly Language（JAL）を書き，ブラウザで実行できるエディタです。命令ごとのスタックの変化を調べたり，ブレークポイントで実行を止めたりしながら，Java のバイトコードを読み書きできます。

エディタには Monaco Editor，実行環境には WebAssembly 上で動く Bovine JVM と OpenJDK 23 を使っています。利用者の PC に Java をインストールする必要はありません。

## まず動かす

最初に開くのは `example/HelloWorld.jal` です。

```jal
public class examples/HelloWorld {
  public static main([Ljava/lang/String;)V {
    getstatic java/lang/System->out:Ljava/io/PrintStream;
    ldc "Hello, JAL!"
    invokevirtual java/io/PrintStream->println(Ljava/lang/String;)V
    return
  }
}
```

右上の **Run** を押すと実行が始まります。Hello World には `invokevirtual` にブレークポイントが置かれているので，文字列を出力する直前で止まります。Debug でスタックを確認してから <kbd>F8</kbd> で再開すると，Console に `Hello, JAL!` が表示されます。

ブレークポイントは行番号とバイトコードオフセットの間をクリックすると切り替えられます。ブレークポイントがなければ最後まで実行します。実行中は Run が Stop に変わり，無限ループも停止できます。

`example` フォルダーには，演算・分岐・ループ・配列・メソッド呼び出しなどのサンプルが入っています。自由に書き換えて試せますが，リロードすると元に戻ります。編集したサンプルを残すには **File → JAL に書き出す…** を使ってください。

## コードを読む・書く

命令とその引数を補完し，構文エラーやスタックの型の不整合を表示します。冗長な命令などはインスペクションで指摘し，修正候補を出します。フォーマッターはラベルをメソッド宣言と同じ深さにそろえます。

命令にマウスを置くと，ソースの解析結果をもとにスタックの実行前後を表示します。消費する値は赤，追加する値は緑です。行番号の隣の数値はメソッド先頭からのバイトコードオフセットで，入力に追従します。この数値は命令サイズから求めた推定値のため，コンパイル後の値と異なる場合があります。

| パネル       | 用途                                                   |
| ------------ | ------------------------------------------------------ |
| PROJECT      | ファイルの作成・名前変更・移動など                     |
| Console      | 実行結果の確認と標準入力の設定                         |
| Problems     | 診断の一覧。項目を押すと該当箇所へ移動                 |
| Instructions | 命令の説明，使用例，スタック・ローカル変数の変化       |
| Graph        | 命令間のスタック・ローカル変数・制御フロー・例外の関係 |
| Debug        | 停止中の呼び出しフレームと値の確認                     |

エディタで命令をクリックすると，Instructions もその命令に切り替わります。Graph はクラス内の各メソッドを順次表示します。命令のクリックでソースへ移動し，背景のドラッグで移動，ホイールで拡大縮小できます。

クラスやメンバーの定義には <kbd>Ctrl</kbd> を押しながらクリックするか，<kbd>F12</kbd> で移動します。OpenJDK のクラスも JAL に逆アセンブルして開きます。ラベルの定義・使用箇所へは <kbd>Shift</kbd>＋クリック，ファイルや定義の検索には <kbd>Shift</kbd> を2回押します。

### ステップ実行

停止中は，画面下部にデバッグ操作が表示されます。

| キー                             | 操作                                       |
| -------------------------------- | ------------------------------------------ |
| <kbd>F8</kbd>                    | 実行を再開                                 |
| <kbd>F10</kbd>                   | 次の命令へ。メソッド呼び出しはまとめて実行 |
| <kbd>F11</kbd>                   | 呼び出し先のメソッドへ入る                 |
| <kbd>Shift</kbd>＋<kbd>F11</kbd> | 現在のメソッドから戻るまで実行             |
| <kbd>F9</kbd>                    | 現在の行のブレークポイントを切り替え       |

Debug の「現在」には，停止時点の JVM の値を表示します。「実行後」は次の命令による変化を示します。メソッドの戻り値など，まだ決まっていない値は型や未確定の値として表示します。変化しないスタックやローカル変数は「（変更無し）」の1列になります。

呼び出し元のフレームを選ぶと，メソッドを呼び出した時点で保存した値を確認できます。実行位置はエディタでも強調表示されます。ネイティブメソッドや JVM 内部の同期呼び出しの途中にはステップインできません。

## ファイルとプロジェクト

**File → 開く…** は拡張子で処理を切り替えます。`.jal` は編集用に開き，`.class` は JAL に逆アセンブルして表示します。`.class` は画面へのドラッグ＆ドロップでも開けます。

複数のソースをまとめて扱う場合は，**File → フォルダーを開く…** で作業フォルダーを選びます。プロジェクト設定は `.jalprj`，ソースは個別の `.jal` ファイルとして保存します。

```text
MyProject/
├── project.jalprj
└── src/
    ├── Main.jal
    └── Helper.jal
```

`.jalprj` は JSON です。最小の設定は次のようになります。

```json
{
  "format": "jalprj",
  "version": 1,
  "name": "MyProject",
  "entryFile": "src/Main.jal"
}
```

実行対象は **File → プロジェクトのプロパティ…** で変更できます。新規プロジェクトでは `src/Main.jal` を使います。プロジェクトの保存・復元には，開いているタブや小窓，配置とサイズも含まれます。

設定ファイルのないフォルダーも開けます。`.jalprj` を「開く…」で選んだ場合は，続けてソースのあるフォルダーを選択します。ブラウザから周囲のファイルへアクセスするために必要な操作です。

フォルダーを開いている間は，約1秒ごとに更新日時とサイズを確認し，ファイルの追加・削除・変更を反映します。未保存の編集と外部の変更が競合した場合は，編集内容を残して通知します。

保存は **File → 保存**，または <kbd>Ctrl</kbd>＋<kbd>S</kbd> です。`example` の内容はプロジェクトやフォルダーの保存対象に含みません。フォルダーへ直接保存できないブラウザでは **ZIP に書き出す…** を使えます。コンパイルした `.class` の書き出しは Build メニューにあります。

## 画面を整える

エディタや各パネルのタブは，少し長押ししてからドラッグすると移動できます。画面の外へ持ち出すと小窓で開きます。タブの右クリックメニューからも小窓を開けます。タブグループの境界をドラッグすると大きさを変えられます。

**View → テーマ** で配色と画面のスタイルを変更できます。初回は端末の明暗設定に合わせて VS Light / Dark を選択した状態で，テーマ選択画面を開きます。

**Help → 機能ガイド** では，左の一覧から使い方やショートカットを調べられます。

吹き出しガイドは × で閉じられます。「すべてスキップ」を押すと残りも閉じます。もう一度見るには **Help → 吹き出しガイドを再表示** を選んでください。

## オフラインで使う

通信できるうちに **Help → オフラインの準備…** を実行すると，エディタと実行環境をブラウザに保存できます。準備が終わったら，同じ URL をオフラインでも開けます。

この機能は本番ビルドで利用できます。開発サーバーでは動作しません。また，ブラウザのサイトデータを削除すると保存した実行環境も消えます。作成したソースは File メニューから別途保存してください。

## 開発環境

必要なものは Node.js 22 以降，pnpm 10.13.1，JDK 23 以降，Git，Python 3，CMake 3.15〜3.31，Ninja です。

```sh
pnpm install --frozen-lockfile
pnpm run setup
pnpm run dev
```

`setup` は実行環境などの取得とビルドを行います。初回は Emscripten 4.0.2 も取得するため，数百 MB のダウンロードが発生します。開発サーバーは通常 `http://127.0.0.1:5173/` で開きます。

Windows では MSYS2 UCRT64 の CMake と Ninja も使えます。C コードのコンパイルには Emscripten の Clang を使います。既存の SDK を指定する方法や JVM パッチの詳細は [vendor/patches/README.md](vendor/patches/README.md) を参照してください。

| コマンド                  | 内容                                             |
| ------------------------- | ------------------------------------------------ |
| `pnpm run typecheck`      | TypeScript の型検査                              |
| `pnpm test`               | テスト。ブラウザを使うテストを含む               |
| `pnpm run build:compiler` | Java 側のコンパイラを再ビルド                    |
| `pnpm run build:runtime`  | パッチを適用した JVM を再ビルド                  |
| `pnpm run build`          | 配布用ファイルとオフライン用キャッシュ情報を生成 |
| `pnpm run preview`        | 配布用ビルドをローカルで確認                     |

公開するファイルは `dist/` に出力されます。HTTPS で配信し，`.wasm` の MIME タイプを `application/wasm` に設定してください。フォルダーの読み書きには File System Access API が必要で，Chrome / Edge での利用を想定しています。ローカル開発では localhost でも利用できます。

### ソースの構成

| 場所                         | 役割                                   |
| ---------------------------- | -------------------------------------- |
| `src/main.ts`                | ワークスペースと各画面の接続           |
| `src/detached*.ts`           | 小窓と親画面の同期                     |
| `src/compilation-service.ts` | コンパイル要求と解析結果の共有         |
| `src/source-analysis.ts`     | エディタの解析とオフセット表示         |
| `src/runtime*.ts`            | Worker 上の JVM・実行・デバッグ制御    |
| `java/src/jalweb/`           | コンパイル・逆アセンブル・フレーム解析 |
| `vendor/patches/`            | JVM に適用するパッチとビルド手順       |

## 実行環境について

OpenJDK 23 のクラスライブラリを同梱していますが，ブラウザ上で通常の Java 環境の全機能を使えるわけではありません。OS のファイル操作，ソケット通信，AWT / Swing，JNI など，ネイティブ実装に依存する機能には制約があります。

実行の入口は `public static main([Ljava/lang/String;)V` です。標準入力は実行前に Console で設定します。Java プログラムはブラウザ内で動き，サーバー上では実行しません。

利用している OSS とライセンスは [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md) にまとめています。

配布用ビルドの公開パスは `/jaspera/` です。`dist` の内容を `https://jal.yamad.jp/jaspera/` に配置します。`pnpm preview` でも `/jaspera/` から確認できます。

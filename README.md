# JALWeb

Monaco Editor で JVM Assembly Language (JAL) を編集し、ブラウザ内の WebAssembly JVM でコンパイル・実行する環境です。初期ソースは `src/Main.jal`（クラス名 `Main`）の Hello World です。

## 起動

ビルドには Node.js 22 以降と JDK 21 以降が必要です。利用者のブラウザには Java のインストールは不要です。

```sh
npm ci
npm run setup
npm run dev
```

表示されたローカル URL を開き、**Run** または **Ctrl+Enter / F5** で実行します。**Stop** は実行用 Worker を破棄するため、無限ループも停止できます。macOS では Cmd+Enter も使用できます。

- 行番号の隣にメソッド先頭からのバイトコードオフセット（10進数）を表示。Javasm と同じ命令サイズの累積方式で、JVM の起動やコンパイルを待たず入力に追従します。wide と switch のパディングに対応。同じ行の複数命令はホバーで確認できます。定数プールや ASM による命令の短縮・拡張を確定させる前の推定値です。
- 命令、キーワード、ラベル、文字列、コメント、型のハイライト。命令は Javasm の18分類（変数アクセス・定数生成・演算・分岐・呼び出しなど）で色分けし、全テーマに合わせた配色を使用。Instructions 辞書でも同じ色を表示します
- 命令とオペランドのスニペット、ラベル・ローカル変数の補完
- 同梱 OpenJDK の公開 1,698 クラスから生成したクラス・メソッド・フィールド補完
- `getstatic` などの命令直後から、フィールド／メソッド・static の条件に合った候補を表示。`System.out`、`java.lang.System.out`、`invokevirtual print`、`invokestatic Math.abs` などでも検索でき、選択時に JAL の所有クラス・記述子へ変換
- 行頭の `print` / `println`、`System.out.println` / `java.lang.System.out.println`（`System.err` も対応）から文字列出力の 3 命令を挿入。文字列は選択状態になり、そのまま編集可能。これはエディタのスニペットであり、Java 構文をコンパイラに追加するものではありません
- 命令ホバーでスタックの実行前→実行後を近接表示。ASM による静的な型解析で、ローカル変数は store／iinc で更新されるスロットだけを表示します。命令ホバードキュメントは表示しません。
- Console / Problems の隣の **Instructions** で命令辞書を閲覧。JVM の命令分類を基にしたカテゴリ、名前・説明の検索、初心者向け説明とスタックの実行前→実行後の図、変更するローカル変数を表示します。dup 系の各形式を切り替えられ、詳しい制約・例外も続けて読めます。検索欄をクリックするとカテゴリと命令一覧が開き、外側をクリックすると閉じます。エディタ内の命令をクリックすると、その命令の説明へ移動します（カーソル移動では切り替わりません）。JVM 起動やビルドを待たず利用できます。
- ラベルへの Ctrl+クリック / F12
- ANTLR と既存 JAL コンパイラ、ASM による文法・スタック・制御フロー検査
- Javasm を参考にしたライブインスペクション。定数プッシュ・ローカル変数命令の短縮、プッシュの範囲外、`wide` の過不足（`iinc` の増分も考慮）、ローカル変数番号の範囲外、戻り値と return 命令の不一致、無条件分岐後の到達不能コードを検出します。`Ctrl+.` / 電球 / Edit → クイックフィックス から修正でき、Undo に対応します。範囲外・型不一致・到達不能コードのうち修正方法が一意でないものは診断のみ。マクロ展開結果は書き換えず、未解決の構文以降は同じメソッドの検査を止めます。JVM の起動やビルドは不要です。
- 標準出力・標準エラー、実行開始時の標準入力、生成した `.class` のダウンロード

## プロジェクトとメニュー

プロジェクトは PC のフォルダーとして扱います。設定は UTF-8 JSON、ソースは独立したファイルです。

```text
MyProject/
  project.jalprj
  src/
    Main.jal
    Helper.jal
```

`project.jalprj` にはプロパティだけを保存します。

```json
{
  "format": "jalprj",
  "version": 1,
  "name": "Main",
  "entryFile": "src/Main.jal"
}
```

- **File → フォルダーを開く**（Ctrl/Cmd+O）: 設定の有無を自動判別します。設定がある場合は `src/` 以下、ない場合は選択したフォルダー以下の `.jal` を再帰的に読み込みます。
- **File → プロジェクトを開く**: 同じ読み込み処理を使用し、直下に `.jalprj` が 1 つあることを確認します。
- **File → プロジェクトを保存**（Ctrl/Cmd+S）: 初回は保存先のフォルダーを選び、その後は同じ場所へ上書きします。追加・名前変更・削除も保存時に反映します。
- **File → 別のフォルダーに保存**: 別の保存先に設定とソースを書き出し、以後の保存先を変更します。
- **File → ZIP にエクスポート**: 同じディレクトリ構成で ZIP をダウンロードします。展開したフォルダーを開けます。
- **File**: 新規プロジェクト、ファイルの追加・名前変更・削除、プロジェクトのプロパティ（名前・実行するファイル）。
- **Edit**: Undo / Redo、検索・置換、行コメント、折り返し、カラーテーマ。
- **Build**: プロジェクト全体の検査、実行、停止、現在のファイルの `.class` ダウンロード。
- **Help**: プロジェクトの説明、ショートカット、使用技術。

設定なしのフォルダーは空でも開けます。プロパティ画面は無効になり、保存ではソースだけを書き込みます。プロジェクトとフォルダーの双方で、約 1 秒ごとに一覧とファイルの更新日時・サイズを確認します。変化したファイルだけ本文を読み直し、追加・削除・変更を Web 側へ反映します。ハッシュ計算は行いません。同じ更新日時・サイズの変更は検出できません。ブラウザがバックグラウンドにある場合は監視間隔が長くなる場合があります。

未保存の編集と外部変更が同じファイルで競合した場合は、編集内容を保持してステータスに表示します。別のフォルダーへの保存や ZIP エクスポートで編集内容を退避できます。

フォルダーへの直接保存には File System Access API 対応ブラウザ（Chrome / Edge）と HTTPS または localhost が必要です。非対応の場合は ZIP エクスポートを利用できます。ブラウザを閉じた後は、再度フォルダーを選択してください。旧 `.jalproj` はサポートしません。

実行するファイルはプロジェクトのプロパティで指定し、既定は `src/Main.jal` です。Run は全ソースをコンパイルし、同じクラスローダーに登録します。ファイル名の変更ではソース内のクラス名・参照は自動変更しません。

未保存の編集は新規作成・読み込み前に確認します。自動保存は行いません。保存時にも外部変更の衝突を確認します。監視で取り込めていない変更や、保存先に既にある同名ファイルは上書きせずエラーにします。無関係なファイルや空のディレクトリは削除しません。複数ファイルの保存は一括トランザクションではなく、途中で失敗すると一部だけ保存される場合があります。その場合は未保存状態を維持します。

標準入力、カーソル位置、表示パネルなどの一時的な作業状態は `.jalprj` には保存しません。テーマはブラウザに保存する個人設定です。設定ファイルは 64 KiB 以下、ソースは最大 64 ファイル・各 1 MiB 以下・合計 6 MiB 以下です。相対パスのみを許可し、重複や親ディレクトリ参照は拒否します。

[複数クラスのサンプル](examples/HelloProject) をフォルダーごと保存し、File → フォルダーを開くで試せます。

**View → テーマ**で Darcula、Visual Studio Light / Dark、High Contrast Light / Dark、JAL Night と画像イメージのテーマを選択できます。

## ビルドとテスト

```sh
npm run build
npm test
```

`npm test` は専用のローカルサーバーを起動・終了します。Windows ではインストール済み Microsoft Edge、その他の環境では Playwright Chromium を使用します。Chromium は `npx playwright install chromium` で取得できます。`JALWEB_BROWSER=chromium` で選択を変更できます。

`dist/` は静的サイトです。`npm run preview` で本番ビルドを確認できます。`dist/runtime/` を含むすべてのファイルを HTTP(S) サーバーで配信してください。WASM は `application/wasm` で配信します。サブディレクトリへの配置に対応します。実行にサーバー側 Java や外部実行 API は使いません。

初回は OpenJDK と JVM を約 55 MB 読み込みます。以後はブラウザの HTTP キャッシュを利用します。2 回目以降を高速化するため、配信サーバーでバージョン付きリリースと適切な Cache-Control を設定できます。

## 構成

- `src/project.ts`: 作業中のプロジェクトのモデルと検証。
- `src/folder-project.ts`: 設定 JSON、フォルダーの読み書き、ZIP エクスポート。
- `src/menus.ts`: マウス・キーボード対応のアプリケーションメニュー。
- `src/language.ts`: Monaco の言語機能。文法と命令説明は `scripts/generate-language.mjs` で生成。
- `src/runtime.worker.ts`: Bovine JVM の起動と Java ブリッジ。解析用 Worker と実行用 Worker を分離。
- `java/src/jalweb/Bridge.java`: 既存コンパイラへの薄いアダプター。UTF-8 入力を Base64、結果を ASCII JSON で受け渡します。
- `java/src/jalweb/Catalog.java`: 同梱 JDK のクラスファイルから補完候補を生成。
- `vendor/langjal/`: 作業開始時の JavaAssemblyLanguage のソースと ANTLR 文法のスナップショット。スタック診断用に命令の構文範囲と消費オペランド位置を保持する変更を含みます。
- `vendor/javasm/`: 既存プラグインの命令ドキュメント。
- `java/patches/java/util/zip/`: JZlib を標準 ZIP API に接続するアダプター。圧縮アルゴリズム自体は再実装していません。
- `vendor/*-lock.json`: 取得 URL・SHA-256。`npm run setup` は整合性を検証します。
- `vendor/provenance.json`: 参照したローカルリポジトリのコミットとスナップショットの説明。

`npm run build:compiler` は文法から Java パーサーを再生成し、コンパイラ JAR とパッチ済み JDK JAR を作成します。原本 JDK は `.cache/runtime/jdk23.jar` に保存します。`PatchRuntime.java` は仮想ファイルシステムで扱えない `FileInputStream.available0` を、閉じたストリームの検査と仕様上有効な 0 の推定値に置き換えます。日時・ZIP 用のタイムゾーンデータは Temurin 23.0.2+7 から取得します。Bovine の上流コードは改変せず保持し、JS の UTF-8 バッファサイズとダウンロード処理の修正をセットアップ時に適用します。

## 実行範囲

OpenJDK 23 の標準クラスを使用します。`tests/StandardLibraryProbe.java` で文字列・数値、コレクション、Stream、正規表現、BigInteger / BigDecimal、日時、メモリ I/O、ByteBuffer・文字コード、SHA-256、URI、書式化、スレッド、圧縮処理を検証します。

現状は **Java SE 全体の完全互換環境ではありません**。Bovine JVM に未実装のネイティブ API があるため、通常のファイルへの書き込み、ファイルを用いる一部 NIO、ソケット・HTTP 通信、AWT/Swing、任意の JNI ライブラリは未対応です。補完カタログはクラスの存在を示し、すべてのメソッドの実行保証ではありません。対応外の API は実行エラーとして表示されます。

1 ファイル = 1 クラス（既存 JAL 文法の単位）です。エントリポイントは `public static main([Ljava/lang/String;)V`、引数配列は空です。各 Run は独立した JVM で実行し、終了時に子スレッドを含めて破棄します。標準入力は入力欄の内容を渡した後 EOF になります。

- 実行時間: 初期ロード込み 30 秒、コンパイルは 60 秒
- Java ヒープ: Worker ごとに 128 MiB
- ソース / 標準入力: 各 1 MiB 以下
- コンソール出力: 256 KiB で打ち切り
- 診断: ファイルごとに最大 100 件（重複クラス診断を除く）
- クラスファイル: Java 23 (major version 67) まで。旧 jsr / ret は Bovine の制約に従います。

診断の行番号は上流コンパイラ由来です。マクロの展開後に検出されたエラーでは、列位置が展開後の位置になる場合があります。データフロー検査は JVM の完全なクラスリンク検証の代わりではなく、存在しないメソッドなどは実行時に検出されます。

### class ファイルの閲覧

`.class` を画面へドラッグ＆ドロップするか、File → 開くで JAL として逆アセンブルします。プロジェクトを開いていなくても利用できます。フォルダー内では `src/` 外の `build/` なども含め、一覧の `.class` をクリックして開けます。開いた class の外部更新・削除も監視します。

逆アセンブルは閲覧専用のタブです。作業中の JAL や元の class を上書きせず、プロジェクトの保存にも混ぜません。File → JAL に書き出すで別途ダウンロードできます。class は各 1 MiB 以下、閲覧タブは最大 16 個です。不正なファイルはエラーを表示し、現在の編集を保持します。

JALP の表記を参考に、解析には ASM を使用します。入力クラスの定義・初期化・実行は行いません。フィールド、メソッド、分岐、switch、例外処理、invokedynamic を表示します。元のソースの復元や完全な class の往復変換ではなく、注釈・ジェネリック署名などの付加情報は省略します。

タブは約 350ms 長押ししてドラッグすると並べ替えられます。エディタ領域の外で離すと別ウィンドウの Monaco エディタで開き、ソースと Undo 履歴を元のワークスペースと共有します。小窓の保存・Run は元のプロジェクトを操作し、実行結果は元の Console に表示します。小窓を閉じるとタブに復帰します。元のワークスペースを閉じると小窓も閉じます。ポップアップがブロックされた場合は「小窓で開く」ボタンから再試行できます。タブの × はホバー時（キーボードフォーカス時とタッチ端末でも操作可能）に表示し、Alt＋クリックで他のタブを閉じます。

クラス名・フィールド名・メソッド名を Ctrl＋ホバーすると参照先を表示し、Ctrl＋クリックまたは F12 で定義の JAL へ移動します。ワークスペースの JAL を優先し、対応する `.class` や同梱 OpenJDK 23 のクラスは閲覧専用で逆アセンブルします。メソッドは完全なディスクリプターでオーバーロードを区別し、継承メンバーは定義元を探します。参照解決のために入力クラスを実行・初期化することはありません。ホバーのみではタブを開きません。小窓からの定義ジャンプは同じ小窓のタブで開きます。存在しない参照にはリンクを表示しません。

小窓上部は File / Edit / Build / Help メニューと複数タブで構成し、保存・実行はメニューまたはショートカットから操作します。File → ワークスペースのファイルを開くから追加でき、タブを閉じても編集内容は保持します。保存先のプロジェクト／フォルダーを元のウィンドウで選択するまでは、小窓の保存メニューを非表示にし、Ctrl+S でもフォルダー選択を起動しません。保存先がある場合だけ同じフォルダーに保存します。

Worker 通信には Comlink を使用します。JVM のコンパイル・実行・逆アセンブル、参照解析、オフセット／インスペクション解析を型付き非同期 API として呼び出します。標準出力と進捗は MessageChannel 上の Comlink API で通知し、完了前に出力を届けます。停止・タイムアウトは Worker を強制終了し、待機中の呼び出しを reject します。Monaco 自身の Worker 通信は Monaco に任せています。

Console / Problems / Instructions は長押しドラッグでエディタ側・出力側のペインへ移動し、タブ列で並べ替えられます。右クリックでも配置・閉じる操作ができます。×はホバー時に表示し、Alt＋クリックで同じペインの他のタブを閉じます。View メニューでパネルの再表示と左右のペイン入替ができます。パネル移動・開閉で出力や検索語は保持されます。

Problems / Instructions / Console は小窓にも配置できます。タブを外へドラッグするか右クリックの「小窓で開く」を使用し、小窓の View メニューから他のパネルも追加できます。診断をクリックすると小窓内に該当ソースを開きます。

PROJECT / エディタ / 出力は3つのタブグループです。PROJECT 自体も移動・閉じる・View メニューからの再表示に対応します。グループの境界をドラッグするとサイズを変更でき、比率はブラウザに保存されます（境界にフォーカスして矢印キーでも変更可能）。

ファイルツリーの JAL ファイルは各グループ、または既存の小窓へドラッグ＆ドロップして開けます。同じワークスペースのモデルを共有するので編集内容は引き継がれます。各グループでは異なるソースを同時に表示できます。タブ移動の長押しは160msです。狭い画面では3グループが縦に並び、上下の境界でサイズを変更します。

命令にマウスを置くと、その位置の静的解析フレームから実行前後のスタックを表示します。Instructions の例と描画処理を共有し、消費・更新する値は赤、追加・更新される値は緑です。変更しない値は通常色のままで、TOP は値の枠外に表示します。Ctrl＋ホバーでは定義ジャンプを優先します。

### エディタと解析の責務

- `editor-platform.ts` は親画面・小窓に共通の Monaco 機能を、言語プロバイダーより先に登録します。
- `compilation-service.ts` はワークスペース単位のコンパイルキューと文書ごとのキャッシュを管理します。診断とスタックホバーは処理中の要求も共有し、小窓は親のサービスを呼び出します。実行用 JVM は独立しています。
- `source-analysis.ts` は JVM を使わない解析の予約・版チェック・破棄とオフセット描画を共通化します。各ウィンドウの Monaco モデルに適用します。
- `workspace-state.ts` は Console・診断一覧・標準入力・実行状態・テーマなどの通知元です。小窓同期で DOM を読み戻しません。文書の編集と Undo は引き続き親側の Monaco モデルを正本とし、小窓へ同期します。

フォルダーの1秒監視と、小窓を外部操作で閉じた場合の検出は、内部状態の通知とは別に維持しています。

File → 開く（Ctrl+O）は拡張子で判別します。`.jal` は編集用として読み込み、`.class` は JAL に逆アセンブルして表示します。`.jalprj` を選んだ場合は、ソースへのアクセスに必要なフォルダーも選択します。File → フォルダーを開くからは、設定ファイルの有無を自動判別します。小窓でも同じ「開く」を使えます。
